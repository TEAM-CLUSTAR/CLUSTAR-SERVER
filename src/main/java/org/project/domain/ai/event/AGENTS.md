# AI 이벤트

- 메모 텍스트·이미지·파일 생성 뒤 임베딩하는 후속 처리를 담당한다. 이벤트는 발생 사실에 필요한 최소 식별자·데이터만 담고, 발행자와 구독자의 결합을 늘리지 않는다.
- 현재 리스너는 `@TransactionalEventListener(phase = AFTER_COMMIT)`을 사용한다. 커밋 이후에만 실행되어야 하는 부수 효과는 이 경계를 보존한다.
- 현재 임베딩 리스너는 `@Async`로 실행된다. 비동기 리스너의 예외가 발행 트랜잭션을 되돌리지 않는 점을 전제로, 실패를 로그와 실패 기록으로 남겨 재처리할 수 있어야 한다.
- 임베딩 실패 기록·해결은 현재 `EmbeddingFailureHandler`의 `REQUIRES_NEW` 패턴을 기본값으로 삼는다. 다른 실패 처리 방식을 제안할 때도 실패를 삼키지 않고 로그와 재처리 가능성을 보장한다.

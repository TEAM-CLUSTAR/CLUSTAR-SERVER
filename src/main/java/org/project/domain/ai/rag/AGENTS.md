# AI RAG 파이프라인

- RAG는 `A/extract → … → D/query → E/retrieve → F/augment → G/generate` 단계와 `pipeline` 조합으로 구성된다. 각 단계는 자신의 변환·검색·프롬프트·생성 책임만 가진다.
- 벡터 저장소·모델 호출은 해당 어댑터/단계 뒤에 숨기며, Controller나 Entity에서 직접 호출하지 않는다. 검색 결과의 사용자 소유권과 입력 범위를 검증한다.
- 프롬프트·디버그 정보·문서에는 토큰, 비밀 설정값, 불필요한 사용자 데이터를 포함하지 않는다. 외부 모델 실패는 재시도·실패 기록의 기존 흐름과 일관되게 처리한다.
- 생성 단계에는 Spring Retry 기반 `@Retryable` 사용 코드가 있다. 재시도 대상은 일시적 모델/네트워크 오류로 제한하고, 사용자 입력 오류나 권한 오류를 무조건 재시도하지 않는다.
